# FitLog App

A modern Next.js fitness web application designed to help users explore workout routines, save favorite plans, and manage their personalized workout schedules seamlessly.

---

## Short Description

FitTrack App allows users to browse through a comprehensive list of workout routines, inspect detailed workout guides, and save or add routines to a custom workout plan. Built with Next.js 15, TypeScript, and React Context, the app provides a smooth, fast, and interactive experience for managing daily fitness goals.

---

## Technologies Used

- Next.js (App Router)
- TypeScript
- TailwindCSS
- ESLint
- DaisyUI
- React Icons
- React Toastify

---

## Key Features

1. **Browse Workout Directory:** Explore a wide array of curated workout routines with dedicated detail pages for each routine.
2. **Personalized My Plan Page:** Add custom workouts directly to a dedicated plan dashboard to stay on top of daily targets.
3. **Save for Later:** Easily bookmark routines using the quick "Button Later" feature to review saved items whenever you're ready.
4. **Dynamic Context State:** Global state management powered by React Context, ensuring real-time UI updates for saved workouts and plans across all pages.
5. **Custom Error & Loading Handling:** Integrated fallback states including custom loading skeletons and 404 pages for robust user navigation.
